# DATASET_AUDIT

Scope: what the cached Stage-B / cross-source corpus (550 images) and the local RRDataset partial actually
contain, measured from files.  Numbers in the acquisition tables are generated by
`scripts/dataset_audit_tables.py` (-> `results/audit/source_acquisition_table.*`), not typed by hand.
Family/ancestry columns are from public literature and are **not verified against the benchmark's own
documentation** (the local manifest records only source name, size, format).  Where a statement is an inference it says so.

Consequences (all measured):
* **Every fake is square with power-of-two sides at a single native size per generator; real images are not.**
  The v1 canonicalizer squash-resizes to 256x256, so ~52% of AIGC-real and ~77% of RR-real images are
  *aspect-distorted* and no fake is.  It also means the resampling history differs by class (identity for 256-native fakes,
  2x/4x LANCZOS downscale for SD-family/Midjourney/SDXL, arbitrary ratios for reals).
* The benchmark evidently re-encoded most images to a single JPEG quantization table (q-table mean 36.2 for every fake except ADM and for
  AIGC-real), so JPEG state is matched *within the benchmark* -- except **ADM (PNG, ~18 bpp)** and **RR-real (different table, mean 20.1)**.
* File-geometry alone (min-side, aspect, squareness, pow2) reaches macro AUROC 0.77 in the crossed real-source x generator holdout, higher than the
  652-feature SD1.5 trajectory (0.68).  See `SCIENTIFIC_AUDIT.md`.

RR real-vs-AI is therefore almost perfectly separable by container format and geometry.  **Do not use raw RR AI-vs-real
performance as evidence about generative trajectories** without a normalization control (Phase 3 pipelines).  The AI class also has
category structure (Culture/Medical/Disasters/Politics/War/normal/production ~150 each, "normal" 572) not matched by real images (single
"real" bucket) -- a semantic-content confound as well.  (`results/audit/rr_partial_inventory.csv`)

## 3. Synthetic sources: architecture / ancestry (literature-based, unverified locally)

| source | family | ancestry / notes | text conditioning | space | era |
|---|---|---|---|---|---|
| ADM | pixel diffusion (UNet) | Dhariwal & Nichol guided diffusion, ImageNet | class-conditional (GenImage-style benchmarks use class prompts) | pixel | 2021 |
| BigGAN | GAN | Brock et al., ImageNet class-conditional | class labels | pixel | 2018 |
| GLIDE | pixel diffusion + upsampler | OpenAI; public small filtered model | text (own transformer) | pixel (cascaded) | 2021 |
| VQDM | discrete-latent diffusion | VQ-VAE codes + discrete diffusion | text/class | VQ latent | 2022 |
| DALL-E 2 | unCLIP: CLIP prior + pixel diffusion cascade | OpenAI, closed weights, API | text via CLIP | pixel (cascaded) | 2022 |
| SD1.4 / SD1.5 | latent diffusion (UNet) | LDM lineage, CLIP ViT-L/14 text | CLIP text | KL-f8 latent | 2022 |
| Wukong | latent diffusion (SD-like) | SD-architecture, Chinese text/data (**inferred**: closely related to SD) | text | latent | 2022 |
| SDXL | latent diffusion (larger UNet) | LDM lineage; 2 text encoders; new VAE | text | latent | 2023 |
| Midjourney | closed commercial | unknown architecture (**cannot be characterized**) | text | unknown | 2023 |

**Family counts.** Latent diffusion in the SD lineage: SD14, SD15, Wukong, SDXL = **4/10 sources (40%)**, and the *probe itself is SD1.5*
(so SD15 images are self-generated; SD14 is a near-identical checkpoint).  Pixel-space diffusion: ADM, GLIDE, DALL-E 2 = 3.  GAN: 1 (BigGAN, class-conditional, ImageNet-only content).
Discrete: 1 (VQDM).  Closed/unknown: 2 (DALL-E 2, Midjourney).  **Zero** DiT/flow/rectified-flow, zero autoregressive, zero consistency/distilled,
zero modern (2024+) commercial or open generators, zero style-GAN/face domains.

## 4. Real sources

| source | n | content | camera/pipeline | notes |
|---|---|---|---|---|
| aigc_benchmark_real | 200 | object-centric photos; sizes (375x500, 333x500, 256...) **look like ImageNet** (inference, unverified) | web photos, benchmark-normalized JPEG | same JPEG table as fakes; content class-aligned with ImageNet-class fakes (ADM, BigGAN, VQDM) |
| rrdataset_real | 100 | scenes/news/culture ("real" bucket), larger, more diverse | different JPEG table (mean 20.1), sizes up to 5184 | heavier downscale to 256px than any fake |

Only **two** real sources; nothing with known camera, no RAW, no phone-vs-DSLR, no social-media-recompressed, no film/scan.  A "held-out real
source" therefore means holding out one of two, which is the maximum the corpus allows and a very weak proxy for real-world diversity.

## 5. Blind spots (ranked by consequence for the scientific question)

1. **Acquisition/geometry mismatch between classes** (Section 1).  Must be controlled before any trajectory claim.
2. **Semantic distribution:** class-conditional ImageNet fakes vs scene photos; no content-matched real/fake pairs beyond the 7 COCO pairs (one generator).
3. **SD-family overrepresentation with the probe inside the family** (confounds "provenance" with "SD compatibility").
4. **No modern DiT/flow, no autoregressive, no consistency models, no 2024+ closed systems.**
5. **Two real sources, both web-scraped/recompressed.**
6. **n = 25 per generator** -- every per-generator AUROC has a wide interval (Section 3 of SCIENTIFIC_AUDIT).

## 6. Recommended small, controlled expansion (do NOT just download more)

1. **Content-matched triplets (highest value).** For ~100 COCO/RR real photographs: neutral description (human COCO caption, *not* BLIP, so no
   probe-side caption feedback) -> generate 1 image each from 3 independent open generators:
   (a) SD1.5 (probe family), (b) an SDXL/SD3-class model, (c) a non-latent or DiT model (e.g. PixArt / DiT-family).  Force **identical output
   size and container** (e.g. all 512x512 PNG then run the shared Phase-3 pipeline on all three classes).  This removes semantic, size, and
   format confounds simultaneously and gives a real x generator x probe design.
2. **Second real pipeline with known acquisition:** a small set of real photos re-encoded through each real source's *and* each fake source's
   pipeline (real-with-fake-pipeline, fake-with-real-pipeline) -- a full cross-processing 2x2 that isolates pipeline vs content.
3. **Two modern generators** not derived from SD (a rectified-flow open model and an autoregressive open model) at 512x512 -- 50 images each is
   enough for an *exploratory* affinity row.
4. Keep 25/generator sources as-is; do not extend them until 1-2 show whether any signal survives.
